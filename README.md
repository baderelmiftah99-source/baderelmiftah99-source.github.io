# Jurees — portfolio replacement site

This repository holds the replacement portfolio site for **jurees.com**: the
Jurees women's-fashion store presented as a portfolio sample of the Shopify
store-building work of Bader Amire (JUREES LLC).

- Built only from the store's **public catalogue** (19 products, titles,
  prices and images exactly as published) — no Shopify payment, no admin
  store export.
- The Shopify store closes on **23 November 2026**; this site is ready
  before then so the domain can be pointed to it (see
  `DOMAIN-CHECKLIST.md`).
- The domain itself is registered at Namecheap until **23 July 2027** — no
  transfer is needed, only a DNS repoint when the owner decides.
